# آوا — مدل کوچک و سریع تبدیل گفتار فارسی به متن

آوا یک مدل کوچک تشخیص گفتار فارسیه؛ کمتر از یک میلیون پارامتر داره و از
صفر روی دیتاست نیشکر آموزش دیده. روی گوشی یا لپ‌تاپ، بدون اینترنت و بدون
سرور کار می‌کنه. جمله‌های کوتاه رو تو چند ده میلی‌ثانیه به متن تبدیل
می‌کنه؛ انقدر سریع که حس لحظه‌ای بودن می‌ده. اسمش «آوا»ست — یعنی صدا.

## برای کی خوبه

اگه یه مدل کوچک می‌خوای که صدا رو در لحظه به متن تبدیل کنه — روی گوشی،
لپ‌تاپ یا یه برد کوچیک، بدون سرور و بدون اینترنت — و صدا فارسیه، این
همون مدله. آوا روی پردازنده معمولی بدون GPU کار می‌کنه، حدود ۵ مگابایت
جا می‌گیره و یه جمله کوتاه رو تو چند ده میلی‌ثانیه برمی‌گردونه.

نسخه انگلیسی این صفحه: [README.md](README.md)

## توی این ریپو چی هست

| مسیر | چیه |
|---|---|
| `models/stt_v6.onnx` | مدلی که واقعاً باید استفاده بشه. ONNX با کوانتیزاسیون int8، ‏۴٫۸ مگابایت. موج صوتی ۱۶ کیلوهرتز رو مستقیم می‌گیره و خروجی CTC می‌ده. محاسبه مل و نرمال‌سازی داخل خود گرافه. |
| `models/best.pt` | چک‌پوینت آموزش با PyTorch، ‏۱۲ مگابایت. |
| `models/stt_v6_int8.tflite` | مدل TFLite با کوانتیزاسیون کامل int8، ‏۱٫۲ مگابایت. ورودی‌ش ویژگی log-mel با شکل (1, 40, 600) است. |
| `model.py` | فقط معماری شبکه، بدون چیز اضافه. |
| `demo/` | مثال‌های قابل‌اجرا: تبدیل یه فایل صوتی به متن، و تستی که مدل رو روی نمونه‌های داخل ریپو اجرا می‌کنه. |
| `training/` | اسکریپت‌ها و راهنمای آموزش همین مدل. |

## چقدر خوبه؟

روی مجموعه اعتبارسنجی نیشکر (۱٬۸۸۴ جمله)، نرخ خطای کاراکتر (CER):

| مدل | CER |
|---|---|
| PyTorch با دقت fp32 | ۰٫۲۴۰۸ |
| ONNX با کوانتیزاسیون int8 | ۰٫۲۴۰۵ |
| TFLite با کوانتیزاسیون int8، جمله‌های تا ۶ ثانیه (۱٬۰۹۱ مورد) | ۰٫۲۵۶۳ |
| TFLite با کوانتیزاسیون int8، همه ۱٬۸۸۴ مورد | ۰٫۳۴۹۲ |

ردیف آخر یه توضیح لازم داره: ورودی مدل TFLite ثابته و حداکثر ۶ ثانیه
است، پس ۷۹۳ جمله بلندتر رو نصف می‌کنه و بیشتر همین اختلاف از همون‌جاست.
خود کوانتیزاسیون تقریباً هیچی از دقت کم نکرده (روی زیرمجموعه کوتاه حدود
۰٫۰۰۳+).

چند عدد دیگه: ۹۹۶٬۷۰۳ پارامتر. فایل ONNX ‏۴٬۷۹۸٬۱۷۹ بایت و فایل TFLite
‏۱٬۱۸۳٬۱۳۶ بایته. توی اپ تست اندرویدی ما، هر جمله روی گوشی POCO M5 بین
۳۲ تا ۶۲ میلی‌ثانیه طول کشید.

## امتحانش کن

```bash
git clone https://github.com/mahdimahdimnm945-dev/ava-persian-stt.git
cd ava-persian-stt/demo
pip install numpy onnxruntime scipy
python test_samples.py
python transcribe.py samples/sample1.wav
```

اگه فقط می‌خوای مدل رو از توی کد خودت صدا بزنی، خلاصه‌ش اینه:

```python
import numpy as np
import onnxruntime as ort
from scipy.io import wavfile

sess = ort.InferenceSession("models/stt_v6.onnx", providers=["CPUExecutionProvider"])
sr, data = wavfile.read("my-recording.wav")
samples = data.astype(np.float32) / 32768.0
logits = sess.run(["logits"], {"waveform": samples})[0]
```

کل خط لوله — تغییر نرخ نمونه‌برداری، شمارش فریم‌ها و دیکد CTC — توی
`demo/transcribe.py` هست. کوتاهه، کپی‌ش کن.

## خروجی واقعی

خروجی واقعی سه نمونه داخل `demo/samples/` که با `python test_samples.py`
گرفته شده. این‌ها رو برای قشنگ نشون دادن انتخاب نکردم؛ سومی خطای
معمول مدل رو نشون می‌ده.

| نمونه | متن درست | خروجی آوا | CER |
|---|---|---|---|
| sample1.wav (‏۲٫۷ ثانیه) | این متخصص می‌گوید | این متخص می‌گوی‌د | ۰٫۱۱۸ |
| sample2.wav (‏۳٫۹ ثانیه) | جمع بندی‌ها و کنکورهای سال پیش | جمعوندی‌ها و کنکورهای سال پیش | ۰٫۰۶۷ |
| sample3.wav (‏۴٫۷ ثانیه) | برای مثال گردش مالی خودش باشه نه فرد دیگه‌ایی. | برای نسال گردش مالی وش باش نفرد دیگ‌ای | ۰٫۲۱۷ |

مدل فقط حروف فارسی، فاصله، نیم‌فاصله و عددهای فارسی رو خروجی می‌ده.
علامت نگارشی و حروف لاتین توی خروجیش نیست.

## به چه دردی می‌خوره

- دستورهای صوتی فارسی روی خود دستگاه، بدون اینکه صدا به جایی فرستاده بشه.
- رابط‌های صوتی که جواب فوری می‌خوان: یه دستور کوتاه روی پردازنده گوشی
  بین ۳۲ تا ۶۲ میلی‌ثانیه به متن تبدیل می‌شه.
- تبدیل گفتار به متن به‌صورت آفلاین روی گوشی یا کامپیوتر.
- کنترل خانه هوشمند، ابزارهای دسترس‌پذیری، اپ‌های یادداشت‌برداری.
- نقطه شروع برای فاین‌تیون روی داده صوتی فارسی خودت.

## کجاها خوب نیست

- فقط روی نیشکر آموزش دیده: گفتار خوانده‌شده، معمولاً با ضبط تمیز.
  اتاق پرسروصدا، لهجه غلیظ، گفتار سریع و حرف زدن هم‌زمان چند نفر
  نتیجه رو خراب می‌کنه.
- خطای معمولش حذف صامت‌هاست، مخصوصاً وقتی تند حرف زده می‌شه.
- ورودی مدل TFLite حداکثر ۶ ثانیه است. مدل ONNX صدای بلندتر هم قبول
  می‌کنه، ولی عددهای بالا روی جمله‌های کوتاه اندازه‌گیری شدن.
- برای استفاده بلادرنگ روی ESP32-S3 با کرنل‌های مرجع TFLM خیلی کنده:
  بالای ۹۰ ثانیه برای هر دستور. این محدودیت سخت‌افزار و کرنله، نه
  اندازه مدل. روی گوشی، کامپیوتر یا بردی با پردازنده درست ازش استفاده کن.

## چطور آموزش دیده

یه شبکه کانولوشن جداشدنی عمقی (DS-CNN) با هد CTC که از صفر روی نیشکر
آموزش دیده: ۶۲٬۲۷۹ کلیپ، حدود ۹۹ ساعت (۵۸٬۱۶۷ تا برای آموزش، ۱٬۸۸۴ تا
برای اعتبارسنجی). بهینه‌ساز AdamW با نرخ یادگیری 2e-3، بچ ۱۲۸، حداکثر
۱۵۰ اپوک با توقف زودهنگام؛ بهترین چک‌پوینت توی اپوک ۱۱۶ به دست اومد.
فرانت‌اند صدا ثابته: ۱۶ کیلوهرتز، پنجره ۲۵ میلی‌ثانیه، گام ۱۰
میلی‌ثانیه، ۴۰ باند log-mel و واژگان ۴۷کاراکتری. دستور کامل، آماده‌سازی
داده و همه جزئیات توی [TRAINING.md](TRAINING.md) هست و اسکریپت‌ها هم
توی `training/` قرار دارن.
